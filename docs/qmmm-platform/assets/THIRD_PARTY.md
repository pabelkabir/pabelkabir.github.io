# Bundled Web Libraries

The QM/MM web workspace vendors these unmodified browser distributions:

- NGL 2.4.0 (`vendor/ngl-2.4.0.js`), MIT License,
  <https://github.com/nglviewer/ngl>
- Lucide 1.26.0 (`vendor/lucide-1.26.0.js`), ISC License,
  <https://github.com/lucide-icons/lucide>

The files were retrieved from the matching npm package distributions through
unpkg. Their original copyright and license notices remain in the bundles.
